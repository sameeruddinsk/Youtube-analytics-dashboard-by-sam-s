# 📊 YouTube Analytics Dashboard By Sam

## 📌 Project Overview

This project is an interactive YouTube Analytics Dashboard developed in Microsoft Excel using VBA, Pivot Tables, Pivot Charts, Slicers, and KPI Cards.

The dashboard automatically analyzes YouTube channel performance and provides visual insights into:

- Total Views
- Watch Time Hours
- Subscribers Gained
- Revenue
- Device Performance
- Traffic Source
- Country Analysis
- Age Group Analysis
- Gender Analysis

---

## 🚀 Features

- One-click Dashboard Generation
